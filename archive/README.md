# Archive

Ce dossier conserve la version précédente du dépôt, sans rapport avec le site de
BONZINILABS LTD.

## `level1-portfolio/`

Le site d'exercice « MR. LASLIE » qui occupait la racine du dépôt jusqu'en août 2026 : un
projet de formation HTML/CSS (page d'accueil, à propos, galerie, contact). Il est conservé
ici tel quel, avec sa feuille de style, et reste consultable en ouvrant
`level1-portfolio/index.html` dans un navigateur — tous ses liens sont relatifs et restent
à l'intérieur du dossier.

**Ce dossier n'est pas publié.** Il est exclu du déploiement par `.vercelignore` sur Vercel
et par une règle 404 dans `netlify.toml`. Le domaine de la société ne sert que les pages de
BONZINILABS LTD : une page d'exercice accessible depuis `bonzinilabs.com` serait un mauvais
signal pour un client comme pour un vérificateur.

Rien ici n'est utilisé par le site en production. Le dossier peut être supprimé à tout
moment sans effet ; l'historique Git en garde trace de toute façon.
